# Análisis de oportunidades de productos latinoamericanos — Florida, EE. UU.

[🇪🇸 Español](README.md) | [🇺🇸 English version](README_EN.md)

## 📌 Descripción del proyecto

Este proyecto analiza oportunidades comerciales para productos latinoamericanos dirigidos al mercado de Florida, Estados Unidos.

Se evaluaron **42 productos de 4 países**:

- 🇲🇽 México
- 🇻🇪 Venezuela
- 🇭🇹 Haití
- 🇬🇹 Guatemala

El análisis combina señales comerciales observadas en:

- Amazon
- Walmart
- eBay

También incorpora información sobre competencia, presencia multicanal y disponibilidad de proveedores en Florida y Estados Unidos.

El objetivo fue transformar una investigación de marketplaces en un conjunto de datos estructurado y en dashboards que permitan identificar productos con mayor potencial comercial.

## 🎯 Objetivos del análisis

El proyecto busca responder preguntas como:

- ¿Qué productos muestran mejores señales comerciales?
- ¿Qué productos tienen presencia en varios marketplaces?
- ¿Qué tan fuerte es la demanda relativa observada en Amazon?
- ¿Qué señales presentan Walmart y eBay?
- ¿Qué productos cuentan con opciones de abastecimiento en Florida o Estados Unidos?
- ¿Qué productos deberían recibir mayor prioridad comercial?

## ⚠️ Nota metodológica

Las clasificaciones de demanda y oportunidad se basan en señales observadas en Amazon, Walmart y eBay, junto con información de abastecimiento.

Estas señales **no representan ventas totales del mercado de Florida**, sino indicadores utilizados para comparar productos y priorizar oportunidades comerciales.
